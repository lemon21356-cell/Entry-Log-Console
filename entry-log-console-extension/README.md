# Entry Log Console

엔트리 말하기 블록의 드롭다운에 `[log]`, `[info]`, `[warn]`, `[error]`, `[debug]`를 추가하고, 선택한 로그를 화면 아래 출력 패널에 표시하는 Chrome/Edge 확장프로그램입니다.

## 설치

1. Chrome 또는 Edge에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. 이 폴더를 선택합니다.
5. 엔트리 만들기 화면을 새로고침합니다.

## 사용

- `안녕! 을(를) 말하기` 또는 `안녕! 을(를) 4초 동안 말하기` 블록의 드롭다운에서 `[log]`, `[info]`, `[warn]`, `[error]`, `[debug]`를 선택합니다.
- 해당 블록이 실행되면 말풍선 대신 아래 출력 패널에 기록됩니다.
- 출력에는 `[log] -- [장면명 / 오브젝트명]`처럼 어느 장면의 어떤 오브젝트에서 발생했는지도 함께 표시됩니다.
- 장면명은 로그가 발생한 오브젝트의 장면 ID를 기준으로 찾아 표시합니다.
- 출력 줄을 클릭하면 해당 장면으로 이동한 뒤 해당 오브젝트를 선택합니다.
- 패널 위쪽을 드래그하면 높이를 늘리거나 줄일 수 있습니다.
- 탭으로 로그 종류를 필터링할 수 있습니다.
- 검색창으로 출력 내용을 검색할 수 있습니다.
- 지우기 버튼 또는 `Ctrl+Shift+L`로 전체 삭제할 수 있습니다.

## 참고

엔트리 웹사이트 구조가 바뀌면 블록 패치 방식도 같이 조정해야 할 수 있습니다. 이 확장프로그램은 현재 엔트리의 `dialog`, `dialog_time` 블록 정의를 페이지 안에서 패치하는 방식으로 동작합니다.
